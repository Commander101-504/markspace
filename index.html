About

Markspace is a simple website that parses markdown code with many quality of life options. Here is a quick explanation of the markdown language.

**text** Bold

*text* Italic

# text Heading

`` Code

[name](url) Link

- text Bullet List

--- Divider

If you don't want to remember this, use the buttons in the toolbar to apply this formatting automatically.
