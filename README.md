# Markspace
---
A simple markdown parser that runs in your browser
You can use markspace in [Netlify](https://markspace.netlify.app/)

## Keyboard Shortcuts
<kbd>Ctrl</kbd> + <kbd>B</kbd> Bold
<kbd>Ctrl</kbd> + <kbd>I</kbd> Italic
<kbd>Ctrl</kbd> + <kbd>H</kbd> Heading
<kbd>Ctrl</kbd> + <kbd>`</kbd> Code
<kbd>Ctrl</kbd> + <kbd>K</kbd> Link
<kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>B</kbd> Bullet List
<kbd>Ctrl</kbd> + <kbd>D</kbd> Divider
