# Markspace
---
A simple markdown parser that runs in your browser
You can use markspace in [Netlify](https://markspace.netlify.app/)

## Keyboard Shortcuts
<kbd>Ctrl</kbd> + <kbd>B</kbd> Bold <br>
<kbd>Ctrl</kbd> + <kbd>I</kbd> Italic <br>
<kbd>Ctrl</kbd> + <kbd>H</kbd> Heading <br>
<kbd>Ctrl</kbd> + <kbd>`</kbd> Code <br>
<kbd>Ctrl</kbd> + <kbd>K</kbd> Link <br>
<kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>8</kbd> Bullet List <br>
<kbd>Ctrl</kbd> + <kbd>D</kbd> Divider <br>
